# Distinct architecture figures

The user rejected the original six scenes' repeated deck, rails, carriage and inspection-light shader. Seven distinct figures now share only lifecycle, accessibility and control infrastructure within the existing Shadowland world. Each has its own bounds, camera, silhouette, optical plane and mechanism. The concepts below were established before geometry and reconciled here with the implemented figures.

Exact part names and shapes are generated into `docs/<id>-instrument-parts.json` from `scripts/instrument-scenes.mjs`. Each scene fits its own camera into an 800×500 view; no common deck dimensions or universal translation defines the family. `scripts/build-instruments.mjs` precomputes geometry, settles painter order and audits 21 mechanism positions. Individual vectors and drivers control each moving part; the renderer reorders parts by depth keys.

## Interaction and rendering contract

The three-stage controls and native inputs drive each mechanism. The optional tour advances every 6.5 seconds while visible; manual changes pause it. Animation eases to the selected pose and settles. PuraMente and Superpowered alone retain a live waveform in stage three while unblocked, visible and outside reduced motion. Other scenes do not gain an unrelated ambient loop. Reels, cabinets and the native bridge are not automatically moving machinery.

`effects.ts` supplies separate shaders registered to each scene's floor or wall surface. World-space soft bounds contain the light; physical SVG foreground pieces preserve occlusion. Dark/paper themes, SVG fallback, keyboard controls, translated labels, reduced motion, offscreen suspension and WebGL context restoration remain available. The native dropdown keeps its 14px arrow inset and 42px right reserve.

All sample inputs and paths are local conceptual data. GraphQL selections do not measure query latency; PuraMente plays no audio or writes HealthKit records; Boom uses fictional configurations; Seen separates provider retrieval from display privacy. The 2018 Superpowered story preserves Java/JNI/Android NDK and Objective-C and claims neither JSI/TurboModules nor a measured speedup.
